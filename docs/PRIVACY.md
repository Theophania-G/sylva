# Sylva 隐私政策

生效日期：2026年8月16日

本隐私政策适用于 Sylva 桌面栅栏整理器（以下简称“本应用”）。

## 1. 信息收集

本应用不收集、不存储、不上传任何可用于识别个人身份的信息（PII），
包括但不限于姓名、账号、联系方式、位置、设备标识等。

## 2. 本地数据

本应用仅在您的设备本地保存运行所需的配置数据，包括栅栏布局、桌面图标
组织方式和背景主题设置。这些数据存储在系统的用户应用数据目录
（%APPDATA%\Sylva）中，不会离开您的设备。

## 3. 权限使用

本应用需要访问 Windows 桌面壳层，以便在桌面上显示和管理图标，并需要
读取桌面上图标对应程序或文件的基础信息以完成整理功能。这些操作仅在
您的设备本地进行。

## 4. 网络与第三方

本应用不包含任何网络通信、广告、分析或第三方 SDK，不会主动连接互联网。

## 5. 数据共享

本应用不会向任何第三方出售、出租或共享您的数据。

## 6. 删除数据

卸载本应用并删除 %APPDATA%\Sylva 目录，即可完全清除所有本地数据。

## 7. 联系我们

如有隐私相关问题，请通过 <https://github.com/Theophania-G/sylva> 的
Issues 联系我们。
